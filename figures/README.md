# Figures

This directory contains visualizations generated by the Jupyter notebook and used to support the analytical findings.

Figures include:

- Annual encounter volume
- Encounter-class distribution
- Encounter-class trends
- Encounter-duration distribution
- Zero recorded payer coverage by encounter class
- Procedure volume versus cost
- Payer claim-cost comparison
- Quarterly inpatient utilization
- Repeat utilization by age group

Chart titles and labels are designed for clear operational interpretation. Because the dataset is synthetic, patient identifiers are not displayed in public-facing figures.

The figures can be regenerated by running the analysis notebook from top to bottom.
