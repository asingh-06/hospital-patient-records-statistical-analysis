# Analysis Results

This directory contains reproducible analytical outputs generated by the Jupyter notebook.

## Generated Outputs

* `annual_encounters.csv` — annual encounter volume and utilization trends
* `encounter_class_summary.csv` — encounter counts and distribution by encounter class
* `coverage_by_class.csv` — payer coverage statistics by encounter class
* `quarterly_inpatient_patients.csv` — quarterly unique inpatient patient counts
* `payer_summary.csv` — payer-level encounter, claim cost, and coverage statistics
* `procedure_summary.csv` — procedure frequency and cost statistics
* `patient_utilization.csv` — patient-level encounter and repeat-utilization measures
* `data_quality_summary.csv` — summary of major data-quality checks
* `statistical_results.csv` — statistical test results and effect-size measures

## Reproducibility

These files are derived from the source data and can be regenerated by running:

`notebooks/hospital_patient_records_complete_analysis.ipynb`

from top to bottom.

Raw source data are not stored in this repository. See `data/README.md` for dataset setup instructions.
